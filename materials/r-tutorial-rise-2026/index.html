Intro to Data Visualization in R

A 2-hour, hands-on introduction to making plots in R with ggplot2, using the Palmer Penguins dataset. For RISE 2026 summer researchers — no prior R needed.

Set up your environment

Everything runs in GitHub Codespaces — nothing to install.

  1. Go to the participant environment repo and click “Use this template” → “Create a new repository”.
  2. On your copy: “Code” → “Codespaces” → “Create codespace on main”.
  3. When it finishes building, open notebooks/00-hello.qmd and run the cell. A penguin chart should appear — that means you are ready.

The datasets

Most of today uses palmerpenguins: measurements of 344 penguins from three species (Adelie, Chinstrap, Gentoo) across three islands. Each row is one penguin; each column is something measured about it (flipper length, body mass, species, island, …).

In the last part we switch to a small plate-reader result — four genes measured in ten samples — to see what real machine data looks like and how to reshape it for plotting.

The session runs in three short cycles of learn a little, then try it:

  • Part A — the elements of a plot: geom, mark, mapping
  • Part B — distributions: histograms and boxplots
  • Part C — tidy data: reshaping wide machine data with pivot_longer()

Hands-on worksheet

You will do this inside your Codespace, in notebooks/01-visualization.qmd. The same steps are shown here so you can read along. We work in three short parts, with a little teaching before each.

The one big idea

Every row in a table becomes one mark on a plot. The geom decides what kind of mark (dots, boxes, bars) and how to draw it. The mapping, written inside aes(), links a column to a property of the mark (its x position, its y position, its colour).

Part A — Read and build a plot

Read a plot

library(tidyverse)
library(palmerpenguins)

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g, color = species)) +
  geom_point()
  • Mark: a dot. Mapping: flipper_length_mm → x, body_mass_g → y, species → colour. Rows per mark: one row = one dot.

Build it up, one line at a time

Start simple, then add one piece at a time:

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()                          # step 1: bare scatter

Add color = species inside aes() to map colour to a column. Compare that with putting color = "navy" outside aes() (inside geom_point()), which sets every dot to the same colour — a setting, not a mapping.

Change the geom, keep the rules

ggplot(penguins, aes(x = species, y = body_mass_g, fill = species)) +
  geom_boxplot() +
  labs(x = "Species", y = "Body mass (g)", fill = "Species")

Same idea, new mark: each box summarises many rows (a five-number summary) instead of one row per mark.

One wrangling move: the pipe

|> means “take this data, then…”. Filter first, then plot:

penguins |>
  filter(species == "Gentoo") |>
  ggplot(aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()

Part B — The shape of one variable

Sometimes you have a single column of numbers and want to see its shape. A histogram cuts the range into bins and counts how many rows land in each:

ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 250)

Try changing binwidth (e.g. 100, 500) and watch the shape change.

A boxplot squeezes each distribution into one box, which is handy for comparing groups:

ggplot(penguins, aes(x = species, y = body_mass_g)) +
  geom_boxplot()

Both answer the same question — what do these numbers look like? — a histogram in full detail, a boxplot as a compact summary for comparing.

Part C — Tidy data: reshape, then plot

Real data often comes off a machine in wide format — one row per sample, with a separate column for each measurement. Here is a small plate-reader result for four genes measured in ten samples:

In your Codespace you will instead read this from a file with read_csv("data/qpcr_plate_wide.csv") — same data, straight off the machine.

ggplot wants tidy data: one row per observation, one column per variable. One gene measured in one sample is an observation, so it should be its own row. Use pivot_longer() to stack the four gene columns into two — a gene column and a signal column:

plate_long <- plate |>
  pivot_longer(gene_A:gene_D, names_to = "gene", values_to = "signal")

Now every row is one measurement, and we can plot it — comparing the two groups gene by gene:

ggplot(plate_long, aes(x = gene, y = signal, fill = group)) +
  geom_boxplot()

The wide table could not make this plot. One pivot_longer() unlocked it — and the pattern (genes C and D switch on with treatment) jumps right out.
